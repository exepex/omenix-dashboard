# Scheduled database check (issue #2): owner checklist

One script does everything. You type only the admin user name and password and the #fno-desk Slack bot token
(`FNO_SLACK_BOT_TOKEN`, from your password manager), all at hidden prompts; press Enter at the token prompt if it is
already saved. The monitor's own password is generated by the script, is never shown, and goes straight into the
GitHub secret. Slack gets the details of any finding, because this repository is public and its logs and issues show
only counts.

- [ ] Once, if missing: `brew install gh`, then `gh auth login` (GitHub.com, HTTPS, log in with the browser).
      `python3 --version` must work (it comes with Xcode's command-line tools).
- [ ] From your clone of `exepex/omenix-dashboard`, after `git pull`, in the terminal set up for X1:
      `platform/owner/setup_monitor.sh`
- [ ] Pass = the last line reads `RESULT: db_monitor ready; first check: OK; GitHub secret saved: yes`, and the lines
      above it say `secret FNO_SLACK_BOT_TOKEN saved` (on the first run) and `variable DB_CHECK_ENABLED=true set`.
  - `first check: ALERT`: the details were printed on your screen only (not in the evidence file). Copy them to
    the orchestrator privately, not into the repository; the setup itself is done.
  - `first check: UNKNOWN`: the check could not connect as `db_monitor`. Run the script again; it sets a new
    password.
- [ ] Optional: commit `platform/evidence/<date>-monitor-setup.txt`. It holds status lines only: no password, token,
      verifier or check details.

**What happens after:**
- **Every hour** GitHub runs the check (Actions, workflow `db-check`). On a finding, or when it cannot check, the run
  fails (GitHub e-mails you), the issue "Database check: alert" is opened or commented with counts only, and the
  details go to #fno-desk.
- **Every Monday** around 03:20 UTC, #fno-desk gets a heartbeat with the last successful check. If it stops coming,
  the check has stopped.
- **Password:** to change the monitor's password later, run the same script again.
