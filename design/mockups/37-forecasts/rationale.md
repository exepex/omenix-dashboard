# 37 Forecast lab: why it looks like this

- **The standing first:** forecasts diagnose market reading and never promote a book, so that line sits above
  everything.
- **Who forecasts, then each question.** The forecaster table shows how each is kept from the answers (plain code,
  sealed same day) and its days counted, so a beginner sees whose record is complete before reading any score.
- **One card per question:** today's answers, each forecaster's average miss score, then the verdict against the fixed
  yardstick as a label with its glyph and word (never colour alone), then when it could settle.
- **Every state is labelled Mock**; the source line names the catalog operation.
